Game Formats


   We will be hosting many different playing levels. Below you can find format-specific rules for each level.

Tier "C": This game will focus on having the least amount of rules to allow for more touches and rallies.


    Net Height:      224-228 cm
    Antennas:      No
    Ceiling obstructions:      Ok
    Hand touches of the net:      Ok
    Body touches of the net:      Ok
    Doubles/Lifts:      Ok
    Foot over centre line:      Ok
    Foot over service line:      Ok
    Throws:      Ok
    Serve re-try:      1 re-serve allowed
    Back row attacks:      No
    Setter dumps:      No
    Dedicated setter:      No, middle sets
    Dedicated middles:      No
    5-1 Rotation:      No
    Premade Teams:      No

Tier "B": This game will require more precision in all areas of the game, still with a focus on improvement and rallies.


    Net Height:      235-238 cm
    Antennas:      Yes
    Ceiling obstructions:      Ok
    Hand touches of the net:      Only light touches
    Body touches of the net:      Only light touches
    Doubles/Lifts:      Ok, but obvious ones should be called
    Foot over centre line:      No
    Foot over service line:      No
    Throws:      No
    Serve re-try:      No
    Back row attacks:      Ok
    Setter dumps:      Ok, but only if ball is not settable
    Dedicated setter:      No, but front row setting is Ok
    Dedicated middles:      No
    5-1 Rotation:      No
    Premade Teams:      No

Tier "A": This game will feature serious and competitive players. It is expected that all rules are followed, similar to a professional game.


    Net Height:      243 cm
    Antennas:      Yes
    Ceiling obstructions:      No
    Hand touches of the net:      No
    Body touches of the net:      No
    Doubles/Lifts:      No
    Foot over centre line:      No
    Foot over service line:      No
    Throws:      No
    Serve re-try:      No
    Back row attacks:      Ok
    Setter dumps:      Ok
    Dedicated setter:      Yes
    Dedicated middles:      Yes, only if 2 players agree, otherwise position is played based on rotational location on court
    5-1 Rotation:      Yes
    Premade Teams:      Ok
